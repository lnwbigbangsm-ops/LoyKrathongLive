# ลอยกระทงสู่ดวงดาว

เกมสำหรับไลฟ์ TikTok วันลอยกระทง คนดูพิมพ์คำอธิษฐานในคอมเมนต์ แล้วกระทงที่มีชื่อเขาจะลอยไปตามแม่น้ำบนจอ พอถึงขอบฟ้ากระทงจะลอยขึ้นเป็นดาว

เกมเป็นหน้าเว็บหน้าเดียว (`index.html`) วาดด้วย canvas ขนาด 1080×1920 แนวตั้ง มีตัวเชื่อม (`bridge.mjs`) ที่อ่านคอมเมนต์ ไลก์ และของขวัญจากไลฟ์ TikTok มาส่งให้เกม

## สิ่งที่ต้องมี

- Node.js 20 ขึ้นไป (พัฒนาบน 24)
- เบราว์เซอร์ Chrome หรือ Edge
- บัญชี TikTok ที่เปิดไลฟ์ได้

## ติดตั้ง

```powershell
git clone https://github.com/lnwbigbangsm-ops/LoyKrathongLive.git
cd LoyKrathongLive
npm install
```

## วิธีเปิด

**ซ้อมก่อนไลฟ์** (คอมเมนต์ ไลก์ และของขวัญเป็นของจำลอง ห้ามใช้ออกไลฟ์จริง):

```powershell
node bridge.mjs --test
```

**ไลฟ์จริง** เริ่มไลฟ์ใน TikTok ก่อน แล้วรัน (ใส่ชื่อบัญชีโดยไม่ต้องมี @):

```powershell
node bridge.mjs ชื่อบัญชีTikTok
```

จากนั้นเปิด <http://localhost:8787> หรือดับเบิลคลิก `start-live.bat` ซึ่งจะถามชื่อบัญชีและเปิดเบราว์เซอร์ให้

จอแนวตั้งด้านซ้ายคือภาพที่เอาไปออกไลฟ์ แผงด้านขวาเป็นแผงควบคุม คนดูไม่เห็น กด `H` เพื่อซ่อนแผง

เปิด `index.html` ตรง ๆ โดยไม่รันตัวเชื่อมก็เล่นได้ แต่ต้องพิมพ์ชื่อและคำอธิษฐานเองทั้งหมด

## สิ่งที่เกิดบนจอ

| คนดูทำอะไร | ผลบนจอ |
|---|---|
| พิมพ์คอมเมนต์ | กระทงพร้อมชื่อและข้อความ ลอยไปขอบฟ้าแล้วกลายเป็นดาว |
| พิมพ์ "สอยดาว" | ดาวตกลงมาเปิดคำทำนาย (มี 72 แบบ) แล้วกลายเป็นกระทงดาว |
| คอมเมนต์อะไรก็ได้ | มีโอกาสได้ดาวคำทำนายแบบสุ่ม (ค่าเริ่มต้น 1 ใน 4) |
| กดไลก์ | ทุก 10 ไลก์เติมแสงจันทร์ 1 แต้ม เต็มดวงแล้วมีพลุและโคมลอยทั้งจอ |
| ตอบควิซถูกคนแรก | ได้กระทงทองและขึ้นชื่อบนจอ |

### ของขวัญ 8 ระดับ

นับจากมูลค่าเหรียญรวมของของขวัญที่ส่ง ทุกระดับเป็นเอฟเฟกต์ล้วน ไม่มีรางวัลและไม่มีการสุ่ม

| เหรียญ | เอฟเฟกต์ |
|---|---|
| 1+ | กระทงทอง |
| 5+ | ฝนดาวตก |
| 10+ | ปล่อยโคมลอย |
| 30+ | ขบวนกระทง 5 ใบ |
| 99+ | พลุชุดใหญ่ |
| 199+ | พลุรูปหัวใจ |
| 500+ | พระจันทร์เต็มดวงทันที |
| 1000+ | พญานาคว่ายข้ามแม่น้ำ |

### ควิซ

มี 30 ข้อเกี่ยวกับลอยกระทง ออกเองทุก 10 นาที ให้เวลาตอบ 20 วินาทีแล้วเฉลยเอง เมื่อมีป๊อปอัพอื่นแทรก กล่องควิซจะย่อและเลื่อนขึ้นด้านบน ปรับรอบเวลาและเวลาตอบได้ในแผงควบคุม

## ปุ่มลัด

| ปุ่ม | ทำอะไร |
|---|---|
| `H` | ซ่อน/แสดงแผงควบคุม |
| `F` | จุดพลุ |
| `L` | ปล่อยโคมลอย |
| `Q` | ถามควิซข้อถัดไป |

## การตั้งค่าที่ควรรู้

- **โหมดคอมเมนต์** ค่าเริ่มต้นคือ "ลอยอัตโนมัติ" ทุกคอมเมนต์ขึ้นจอทันทีโดยไม่กรอง ถ้าเจอคำหยาบหรือสแปม ให้ติ๊ก "กรองคำหยาบ/สแปม" หรือเปลี่ยนเป็น "อนุมัติก่อนลอย"
- **ความเร็วกระทง** ค่าเริ่มต้น 75 วินาทีถึงขอบฟ้า เลขมากคือช้า
- **โหมดเบาเครื่อง** ลดความละเอียดเหลือ 720×1280 ใช้เมื่อตัวเลข "ความลื่น" ต่ำกว่า 40 เฟรม/วินาที
- **รีเซ็ตคืนนี้** ล้างยอดกระทง แสงจันทร์ ดาว และอันดับผู้สนับสนุน ควรกดหลังซ้อมและก่อนไลฟ์จริง

ค่าที่ตั้งและยอดสะสมเก็บในเบราว์เซอร์ของเครื่องนั้น (localStorage) ไม่ได้ตามไปเครื่องอื่น

## โครงสร้างไฟล์

```
index.html        ตัวเกมและแผงควบคุมทั้งหมด
bridge.mjs        ตัวเชื่อม TikTok และเว็บเซิร์ฟเวอร์ที่พอร์ต 8787
start-live.bat    เปิดเกมด้วยการดับเบิลคลิก
art/cut/          ภาพที่เกมใช้จริง (กระทง 7 แบบ พญานาค ฉาก พระจันทร์)
art/raw/          ภาพกระทงต้นฉบับจาก Codex และคำสั่งที่ใช้สร้าง
art/naga/ art/scene/ art/moon/   ภาพต้นฉบับและคำสั่งของแต่ละชิ้น
art/key.py        ตัดพื้นหลังกระทงและหาตำแหน่งเปลวเทียน
art/naga_cut.py   ตัดพื้นหลังพญานาค
art/scene_cut.py  เตรียมภาพฉากและพระจันทร์
```

ถ้าไฟล์ใน `art/cut/` หาย เกมยังเล่นได้ โดยจะกลับไปใช้ภาพที่วาดด้วยโค้ดแทน

## สร้างภาพใหม่

ภาพทั้งหมดสร้างด้วย Codex CLI (ต้องเปิดฟีเจอร์ `image_generation`) บนพื้นหลังสีบานเย็น `#FF00FF` แล้วตัดพื้นหลังด้วย Python (ต้องมี Pillow และ numpy)

```powershell
cd art\raw
codex exec -s workspace-write --skip-git-repo-check - < job1.txt
cd ..\..
python art\key.py art\raw art\cut
```

`key.py` จะพิมพ์ค่าตำแหน่งของแต่ละภาพและเขียนลง `art/cut/meta.json` ถ้าเปลี่ยนภาพกระทง ต้องคัดลอกค่าใน `meta.json` ไปแทนค่า `SKMETA` ใน `index.html` ด้วย

## ข้อควรระวัง

- **ตัวเชื่อมไม่ใช่ช่องทางทางการของ TikTok** ใช้ไลบรารี `tiktok-live-connector` ซึ่งเป็นงานแกะระบบ วันที่ TikTok เปลี่ยนระบบอาจใช้ไม่ได้ ถ้าหลุดกลางไลฟ์ ให้พิมพ์เองในช่อง "ลอยกระทง" ของแผงควบคุม
- **ไลบรารีส่งชื่อบัญชีไปที่บริการ Euler Stream** เพื่อขอเชื่อมต่อ ไม่ได้ส่งรหัสผ่าน แบบฟรีมีจำกัดจำนวนครั้ง ตัวเชื่อมจึงเว้น 30 วินาทีก่อนลองใหม่
- **ต้องมีคนโฮสต์จริงตลอดไลฟ์** กฎ TikTok ไม่ให้รายได้กับไลฟ์ที่รันด้วยเครื่องมือโดยไม่มีคนพูดคุย ไลฟ์ที่อัดไว้ล่วงหน้า หรือการขอของขวัญซ้ำ ๆ
- **อย่าผูกของขวัญกับการลุ้นรางวัล** การจ่ายเพื่อลุ้นของมีค่าเข้าข่ายการพนัน
- **หน้าต่างเกมต้องมองเห็นอยู่ตลอด** Chrome หยุดวาดภาพเมื่อหน้าต่างถูกบังสนิทหรือย่อไว้
- **แถบของ TikTok บังบางส่วนของจอ** ด้านบนมีชื่อโปรไฟล์ ด้านล่างมีคอมเมนต์ ควรเปิดไลฟ์ทดสอบดูตำแหน่งก่อนงานจริง

## สถานะ

ทดสอบครบทุกฟีเจอร์ในโหมดทดสอบแล้ว ตัวเชื่อมติดต่อ TikTok ได้ แต่ยังไม่เคยทดสอบกับไลฟ์ที่ออนไลน์อยู่จริง โดยเฉพาะมูลค่าเหรียญของของขวัญ
